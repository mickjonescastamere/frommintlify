Hookline bills per workspace. Only the **live** environment counts toward usage. Test environment messages are free and unlimited within [rate limits](/api-reference/rate-limits).

## How messages are counted

Hookline counts one message each time you create a message with the API, regardless of how many endpoints receive it.

- A message fanned out to 5 endpoints counts once.
- Retries and manual resends don't count.
- Messages deduplicated by `event_id` or `Idempotency-Key` don't count. See [Idempotency](/sending/idempotency).
- A message with no matching endpoints still counts.
- [Operational webhooks](/features/operational-webhooks) don't count.

<Tip>
  To avoid paying for messages nobody receives, check whether an application has any enabled endpoints before you send. Most teams skip creating messages for customers who haven't set up webhooks.
</Tip>

## Track usage

Go to **Settings** > **Usage** to see:

- Messages sent this billing period, with a daily chart.
- Top applications by message volume.
- Your projected total for the period.

Owners and Admins get an email when usage reaches 80% and 100% of the Free plan quota.

## What happens at the Free quota

When a Free workspace reaches 50,000 messages in a month, the API returns `429` with the code `quota_exceeded` for new messages. Hookline still delivers and retries messages that were already accepted. Upgrade to Pro to keep sending immediately.

## Change your plan

1. Go to **Settings** > **Billing**.
2. Click **Change plan** and pick a plan.
3. Enter payment details if prompted.

Upgrades take effect immediately. Downgrades take effect at the end of the billing period. Features that the new plan doesn't include, such as transformations, stop running on that date.

## Invoices

Owners can download invoices and update the billing email under **Settings** > **Billing** > **Invoices**.
