The Node.js SDK supports Node.js 18 and later and ships with TypeScript types.

## Install

<CodeGroup>

```bash npm
npm install @hookline/node
```

```bash pnpm
pnpm add @hookline/node
```

```bash yarn
yarn add @hookline/node
```

</CodeGroup>

## Initialize the client

```javascript
import { Hookline } from "@hookline/node";

const hookline = new Hookline(process.env.HOOKLINE_API_KEY);
```

<ApiKeyWarning />

## Send a message

```javascript
// Create the application once, when the customer turns on webhooks
await hookline.applications.create({ name: "Acme Corp", uid: "cus_1931" });

// Send events whenever something happens
const message = await hookline.messages.create("cus_1931", {
  eventType: "invoice.paid",
  eventId: "evt_2bX9",
  payload: {
    type: "invoice.paid",
    id: "evt_2bX9",
    created_at: new Date().toISOString(),
    data: { invoice_id: "inv_8842", amount: 4900, currency: "usd" },
  },
});

console.log(message.id); // msg_...
```

## Manage endpoints

```javascript
const endpoint = await hookline.endpoints.create("cus_1931", {
  url: "https://example.com/webhooks",
  eventTypes: ["invoice.paid", "invoice.payment_failed"],
});

const { key } = await hookline.endpoints.getSecret("cus_1931", endpoint.id);
```

## Iterate over lists

List methods return an async iterator that fetches pages as you go:

```javascript
for await (const app of hookline.applications.list({ limit: 100 })) {
  console.log(app.uid, app.name);
}
```

## Handle errors

```javascript
import { HooklineError } from "@hookline/node";

try {
  await hookline.messages.create("cus_unknown", { eventType: "invoice.paid", payload: {} });
} catch (err) {
  if (err instanceof HooklineError) {
    console.error(err.status, err.code, err.requestId);
  } else {
    throw err;
  }
}
```

## Verify incoming webhooks

Use the `Webhook` class on the receiving side. Pass the **raw** request body; parsed and re-serialized JSON won't match the signature.

```javascript
import { Webhook, WebhookVerificationError } from "@hookline/node";

const wh = new Webhook(process.env.HOOKLINE_WEBHOOK_SECRET);

export async function POST(request) {
  const body = await request.text();
  try {
    const event = wh.verify(body, Object.fromEntries(request.headers));
    // handle event.type
    return new Response(null, { status: 204 });
  } catch (err) {
    if (err instanceof WebhookVerificationError) return new Response(null, { status: 400 });
    throw err;
  }
}
```

## Configuration options

| Option       | Default                                | Description                           |
| ------------ | -------------------------------------- | ------------------------------------- |
| `serverUrl`  | `https://api.hookline.example/v1`      | API base URL. Use the EU URL for EU workspaces. |
| `maxRetries` | `2`                                    | Retries for `429` and `5xx` responses. |
| `timeout`    | `30000`                                | Request timeout in milliseconds.      |
