Before you begin, make sure you have:

- A Hookline account. Sign up at [app.hookline.example](https://app.hookline.example) if you don't have one.
- A **test** environment API key (it starts with `hl_test_`). Create one in **Settings** > **API keys**.
- An HTTPS URL that can receive `POST` requests. For local development, use [`hookline listen`](/cli/local-development).
